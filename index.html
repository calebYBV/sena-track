    Filtro de primer orden: suavizado gradual con una constante de tiempo τ.

    Ver cálculo numérico

    Euler explícito; se divide el intervalo entre cuadros para que cada subpaso sea como máximo τ/4:

    n = max(1, ceil(dt / (τ/4))) · h = dt/n
    Repetir n veces: y = y + h × (u − y) / τ

    Euler semiimplícito: primero se actualiza la velocidad y luego la posición. El tiempo entre cuadros se divide en subpasos conservadores.

    hMax = min(0.1/ωₙ, 0.1/(2ζωₙ)) · n = max(1, ceil(dt/hMax)) · h = dt/n
    a = ωₙ²(u − y) − 2ζωₙv
    v = v + h × a · y = y + h × v

    No se aplica una ecuación de filtro adicional; se devuelven las coordenadas de entrada.
